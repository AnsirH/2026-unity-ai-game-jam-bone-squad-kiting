# 결정 기록

> 결정은 사람이 내린다. AI는 기록을 돕는다.
> AI가 제안한 결정은 상태를 "제안됨"으로 적고, 사람이 승인하면 "유효"로 바꾼다.
> 결정을 바꿀 때 이전 줄을 지우지 않는다. 새 번호로 추가하고 이전 줄의 상태를 "대체됨 (#새 번호)" 또는 "일부 대체됨 (#새 번호: 바뀐 부분)"으로 바꾼다.
> 기획을 바꾸는 결정은 `docs/PLAN.md` 해당 장을 같은 커밋에서 고친다.

상태: 제안됨 → 유효 → 일부 대체됨 / 대체됨. 받아들이지 않은 제안은 "철회"로 남긴다.
