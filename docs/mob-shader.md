# 아군·적 몹 PBR 셰이더

몹 머티리얼의 Shader 메뉴에서 `Bone Squad/Mob PBR`을 선택한다. 아군은 가장자리와 피격 발광이 모두 밝은 하늘색이고, 적은 두 효과 모두 빨간색이다. 새 모델을 추가할 때는 몸과 장착 무기에 같은 진영 설정을 적용한다.

`Assets/Art/Material/MobExamples`의 `AllyMobExample`과 `EnemyMobExample`은 진영별 부모 머티리얼이다. 병사·분대장과 장착 무기는 아군 설정을 상속한다. 근접병·마법사·암흑 화염 마법사·투석기·창투척병과 창투척병의 창은 적 설정을 상속한다. 전용 프리팹이 없는 유닛과 보스의 기본 머티리얼에도 같은 설정을 적용한다.

새 모델을 추가할 때는 해당 진영의 예시에서 **Create Material Variant**를 선택한다. 자식 머티리얼의 `Base Map`에 모델 고유 텍스처를 지정하고 해당 메시의 렌더러에 연결한다. 진영 전체의 프레넬과 피격색을 바꿀 때는 부모 머티리얼을 수정한다.

| 진영 | 프레넬·피격 발광색 (Unity Color RGB) | Fresnel Intensity |
| --- | --- | --- |
| 아군 | (0.18, 0.346, 1) | 0.5 |
| 적 | (1, 0, 0) | 0.75 |

| 인스펙터 항목 | 사용법 |
| --- | --- |
| Base Map, Base Color | 텍스처와 색상을 곱해 표면색을 정한다. 두 알파 값은 모두 디더링에 반영한다. |
| Metallic, Smoothness | 배경 PBR과 같은 방식으로 금속성과 매끄러움을 조절한다. `Use Metallic Smoothness Map`을 켜면 맵의 R이 금속성을 정하고 A에 `Smoothness`를 곱한다. 맵의 sRGB 설정은 끈다. |
| Use Normal Map | 임포트 타입이 Normal map인 텍스처를 넣고 `Normal Strength`로 강도를 조절한다. |
| Use Emission Map | 켜면 같은 UV의 RGB 발광 맵에 HDR `Emission Color`를 곱한다. 검은 영역은 발광하지 않는다. 피격과 프레넬은 발광 맵과 별도로 더해진다. |
| Hit Flash Color, Hit Flash Intensity | 피격 순간 표면 전체에 더할 진영 색과 최대 발광 강도(0~10)를 정한다. 기본 강도는 3이며, 0이면 피격 발광이 꺼진다. |
| Fresnel Color, Intensity, Power | 모델 가장자리에 더할 빛의 색과 밝기를 정한다. Power를 높이면 빛이 가장자리로 좁아지고, Intensity를 0으로 두면 꺼진다. |
| Opacity | 1에서 0으로 낮추면 픽셀이 4×4 디더 패턴으로 사라진다. 최종 불투명도는 `Opacity × Base Color 알파 × Base Map 알파`이며, 남은 픽셀은 깊이를 기록한다. |
| Dissolve Amount | 0이면 온전한 모델이고, 1이면 모두 사라진다. 중간값에서는 모델 UV를 따라 노이즈 무늬로 사라진다. 별도 노이즈 텍스처는 필요 없다. |
| Noise Scale, Edge Color, Edge Width | Scale을 높이면 디졸브 무늬가 작아진다. Edge Color는 사라지는 경계의 발광색이며, Edge Width를 0으로 두면 경계 발광이 꺼진다. |

그림자와 카메라 깊이·노멀에도 같은 디졸브가 적용된다. 디더 패턴은 카메라 패스에서는 화면 픽셀, 그림자 패스에서는 섀도 맵 픽셀을 기준으로 계산한다.

피격 시 해당 개체 렌더러의 `MaterialPropertyBlock`에서 `_HitFlashAmount`를 1로 설정한 뒤 0으로 낮춘다. 1이면 설정한 밝기로 빛나고, 0이면 원래 모습으로 돌아간다. 무기나 갑옷도 함께 빛나게 하려면 각 머티리얼에 이 셰이더를 지정한다.

연출 코드에서는 개별 렌더러의 `MaterialPropertyBlock`으로 `_Opacity`와 `_DissolveAmount`를 0~1 범위에서 조절한다. 피격 발광은 디더와 디졸브를 통과한 표면에만 더해진다.

서리 기사 보스의 몸체는 `FrostKnight_Armor`를 사용한다. 대기와 차징 등장 중에는 2048px 발광 맵의 투구·흉갑 문양이 은은한 서리빛을 낸다. 일어선 뒤, 차징 공격 끝, 마지막 포효에서 본체가 사라질 때는 문양과 디졸브 경계가 강하게 빛난다. 판금에는 금속성(R)과 매끄러움(A)을 담은 맵을 적용했다. 푸른 프레넬의 강도는 0.035, Power는 4.6이며 피격 강도는 0.18이다. `BossView`는 자식의 스킨드 메시 렌더러에 피격량을 전달하고, 스킨드 메시가 없는 기본 보스는 루트 렌더러를 사용한다.

서리 기사 프리팹의 대검은 전용 머티리얼 `FrostKnight_SummonedBlade`를 쓴다. `FrostKnightSwordReveal`이 공격의 재생 시간에 맞춰 칼 렌더러의 `_DissolveAmount`를 1에서 0으로 낮춘다. 앉아서 찍기는 1.5초, 차징은 2.4초, 착지 찍기를 단독으로 시작하면 0.29초 동안 나타난다. 소환 중에는 칼날 고유의 서리빛을 사용하고, 사라지는 동안 경계와 칼날에 청보라색 발광을 더한다. 손 올리기에서 앉아서 찍기로, 차징에서 착지 찍기로 이어질 때는 직전 디졸브 진행도를 이어받는다.

대검은 타격 순간까지 온전히 보인다. 앉아서 찍기에서는 마지막 1.1초, 차징 공격에서는 마지막 0.62초에 걸쳐 사라진다. 차징에서 착지 찍기로 이어지면 착지 클립의 마지막 0.35초에 소멸을 마친다. 앉아서 찍은 뒤에는 0.48초 동안 왕좌 대기 자세로 돌아간다.

사망 모션의 마지막 포효가 시작되면 `FrostKnightDeathDissolve`가 약 1.1초 동안 갑옷을 청보라색 경계부터 디졸브시키고 두 겹의 남색 아우라도 함께 흐리게 한다. 평상시 아우라는 몸 가까이에서 초당 35개, 바깥으로 길게 뻗는 층에서 초당 23개의 입자를 방출한다. 사망 자세를 유지하는 동안에는 사라진 상태를 유지한다.

서리 기사는 `StandUp`을 끝까지 재생한 뒤 약 1초에 걸쳐 사라진다. 갑옷 문양과 아우라는 디졸브가 진행되는 동안 밝아진다. `ChargedSlash`에서는 첫 1.35초 동안 본체가 나타난다. 대검은 첫 2.4초 동안 나타나고, 마지막 0.62초에 본체와 대검이 함께 빛나며 사라진다.

무릎 꿇고 검을 꽂는 `SwordPlant`의 접지 시점(0.25초)에 푸른 불길이 한 번 솟는다. 씬 계층에서 보스 아래의 **Sword Plant Fire Area**를 선택하고 이동·회전 도구로 위치와 방향을 정한다. 크기 도구에서 X와 Z로 사각형의 폭과 깊이, Y로 불길 높이를 조절한다. 선택 시 보이는 상자의 아랫면을 바닥에 맞춘다. 지속 시간은 같은 오브젝트의 **Burn Seconds**에서 설정한다(기본 1.65초).
