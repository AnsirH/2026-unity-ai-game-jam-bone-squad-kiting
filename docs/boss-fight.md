# 서리 기사 보스전

보스 스테이지(`Game` 씬의 세 번째 스테이지)에서 벌어지는 전투의 규칙과 조절 방법이다. 2026-11-19에 사용자가 승인한 내용대로 구현했다.

## 구성

| 무엇 | 어디 | 역할 |
| --- | --- | --- |
| 전장 표식 | `BossStage` 아래 `Boss Arena` (`BossArena`) | 이 오브젝트가 있는 스테이지가 보스 스테이지가 된다. 위치는 왕좌 방 바닥의 한가운데, 파란 Z축이 왕좌 쪽이다. `Size`가 전투에 쓰는 바닥의 가로·세로다. |
| 왕좌 자리 | `Boss Arena/Throne Seat` | 보스가 앉는 위치와 방향 |
| 마법사 등장 지점 | `Boss Arena/Mage Spawn 1, 2` | 전환 구간에 마법사가 나타나는 곳 |
| 보스 모델 | `Boss Arena/FrostKnight` (`FrostKnightView`) | 모션, 이펙트, 효과음, 카메라 흔들림 |
| 규칙 | `FrostKnightFight` (코드) | 상태 진행, 범위, 피해. `GameDirector`가 매 프레임 진행시킨다 |

보스 스테이지는 보스가 죽어야 클리어된다. 끝 지점에 도착하는 것으로는 클리어되지 않는다.

## 흐름

1. **대기**: 분대가 왕좌 방에 들어오기 전까지 보스는 고개를 숙이고 앉아 있다.
2. **1페이즈**: 왕좌에 앉은 채 대검을 내려찍는다. 두 패턴 모두 시전 시점의 분대 중심을 조준한다. 빈자리 두 곳에도 같은 예고와 이펙트가 동시에 보이며, 이 추가 연출은 피해를 주지 않는다. 두 줄 참격은 세 세트가 서로 다른 방향으로 나아간다. 검이 닿는 순간 두 줄 공격(매번 각도가 달라짐) 또는 원형 공격(경고가 시작될 때 분대가 있던 자리, 원형 진형 E로 벌리면 피해진다) 중 하나가 터진다. 분대는 보스를 공격할 수 있지만 체력은 60% 아래로 내려가지 않는다.
3. **전환**: 체력이 60%가 되면 보스가 기절하고 공격 대상에서 빠진다. 마법사 두 마리(암흑 화염 마법사, 염동 마법사)가 나타난다. 둘 다 처치하면 보스가 일어서며 사라진다.
4. **2페이즈**: 보스는 보이지 않다가 공격할 때만 나타난다. 가로 차징 → 가로 차징 → 즉사 내려찍기 → 가로 차징을 버티면 그로기에 빠져 방 한가운데에 6초 동안 머문다. 그로기와, 가로 차징 중 공중에서 검을 들고 있는 동안에만 공격할 수 있다. 체력이 남으면 다시 사라지고 같은 순서를 반복한다.
   - **가로 차징**: 방의 왼쪽이나 오른쪽 끝에서 장판 세 줄이 길게 뻗는다. 보스의 발이 바닥에 닿을 때 한 번, 세 검기가 나갈 때 한 번 화면이 흔들린다.
   - **즉사 내려찍기**: 왼쪽 절반, 오른쪽 절반, 가운데 50% 중 한 곳을 입구부터 왕좌 쪽 끝까지 경고한다. 타격 순간 같은 사각형 전체에 푸른 불길이 솟는다. 같은 곳이 연달아 나오지 않는다. 범위 안의 병사는 즉사하고, 분대장이 범위 안에 있으면 분대 전체가 쓰러진다.
   - **그로기**: 보스가 방 중앙에 내려오면 착지 충격으로 화면이 흔들리고 갑옷의 파란 윤곽이 0.8초 주기로 점멸한다. 피격색은 보스 몸 전체에 최대 30%로 겹친 뒤 사라진다.
5. **종료**: 체력이 0이 되면 카메라가 45도 하향 구도로 보스에게 가까이 다가가 사망 모션과 디졸브를 크게 비춘다. 연출이 끝나면 카메라가 분대 구도로 돌아온 뒤 클리어 화면이 열린다. 사망 모션이 시작되면 약한 진동이 서서히 커진다. 디졸브 직전 0.85초 동안 진동이 한층 커지고, 디졸브 시작 순간 0.16초 동안 가장 강한 충격이 들어간다.

## 조절

`Boss Arena`의 `Tuning`에서 바꾼다. 플레이 중에 바꿔도 다음 공격부터 적용된다(체력은 다음 시작부터).

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `Max Hp` / `Phase One Ends At` | 체력, 1페이즈가 끝나는 체력 비율 | 30000 / 0.6 |
| `Slam Hit Seconds` | 손을 들고부터 검이 닿기까지(1페이즈 경고 시간). 모션에 맞춘 값 | 2.9초 |
| `Parallel Inner/Outer/Half Length/Max Angle` | 두 줄의 안쪽·바깥쪽 거리, 길이의 절반, 최대 회전 각도 | 2 / 6.5 / 20 / 40도 |
| `Circle Radius` / `Circle Scales With Squad` | 원형 공격 반지름. 원형 진형(E, 반지름 3.7)으로 피하는 공격이므로 그보다 작게 둔다. 켜 두면 분대원이 줄 때 진형과 같은 비율로 원도 줄어든다 | 3.1 / 켜짐 |
| `Hit Damage` | 즉사가 아닌 공격의 피해 | 55 |
| `Mages` / `Mage Delay` | 등장하는 마법사 목록, 기절 후 등장까지 시간 | 2마리 / 1.2초 |
| `Attack Order` | 그로기 사이의 공격 순서. C = 차징, L = 즉사 | `CCLC` |
| `Charge Anim Speed` | 차징 모션 기본 속도. 검이 닿기 전 구간의 재생 시간은 35%이고, 이후에는 기본 속도로 재생한다 | 1.5 (약 1.63초 후 발사) |
| `Charge Can Be Hit` | 차징 중 공중에서 검을 든 동안(모습을 드러낸 뒤부터 베기 전까지) 공격할 수 있음 | 켜짐 |
| `Charge Row Width/Gap Padding/Shift` | 한 줄의 폭, 일자 진형 병사 간격에 더하는 여유, 위아래 이동 한계. 차징 세 줄 사이의 각 통로는 (병사 간격 + 여유)의 두 배 | 5 / 0.12 / 3 (기본 통로 폭 1.22m) |
| `Lethal Warn Seconds` / `Lethal Center Share` | 즉사 경고 시간, 가운데 구역의 폭 비율 | 2.4초 / 50% |
| `Lethal Kills Leader` | 분대장이 즉사 범위에 있으면 분대 전체가 쓰러짐 | 켜짐 |
| `Groggy Seconds` | 그로기 시간 | 6초 |
| `Die Anim Speed` | 사망 모션 속도 | 1.6 |

연출 쪽 값(카메라 흔들림, 효과음 ID, 원형 공격의 대검 낙하 이펙트)은 `FrostKnight`의 `FrostKnightView`에 있다.
