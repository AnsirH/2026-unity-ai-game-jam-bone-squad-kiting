# 제자리 연속 명중과 공격속도

병사와 커맨더는 제자리에서 실제로 명중시킬 때 개인별 공격속도가 증가한다. 기본값은 명중당 1.01배 누적, 최대 1.25배(23회 명중)다. `GameTuning.asset`의 Stationary attack streak에서 증가량·상한·유예 시간을 변경한다.

이동하면 공속 배수가 기본 초당 0.10씩 1.0까지 감소한다. `GameTuning.asset`의 Moving Speed Decay Per Second로 감소 속도를 조절한다(0은 이동 시 감소 없음). 멈춰 공격을 재개하면 남은 배수부터 증가한다. 부활·사망하면 초기화한다. 공격 가능한 적이나 날아가는 자기 투사체가 없으면 기본 1초 후 초기화한다. 이동 전에 발사한 투사체가 뒤늦게 명중해도 새 중첩을 만들지 않는다. 진행 중인 공격은 시작할 때의 속도를 유지한다.

최대 상태에서는 각 유닛에 `Assets/Art/Effect/Buff.prefab`을 하나 생성해 재사용한다. 상태가 풀리면 비활성화하고 남은 파티클을 지운다. `ArtSet.asset`의 Attack Speed Buff Prefab / Height / Scale로 외형을 설정한다. 기본 Scale은 0.12이며 파티클 크기가 이를 따르도록 Hierarchy 모드를 사용한다.

`ArtSet.asset`의 Show Attack Speed Buff 토글로 Buff 표시만 끄거나 켠다. 공속 증가 효과는 그대로 유지한다.

HUD 왼쪽 중앙의 HIT 수는 분대 전체 실제 명중 횟수다. 명중 시 숫자가 커졌다 돌아오며, 기본 2초 동안 명중이 없으면 초기화한다. 아래 ATK SPD는 살아 있는 분대원 중 가장 높은 실제 공속 배수로, 최대치에서는 빨간색이다. 이동 중 감소하는 실제 배수를 계속 표시하며, 명중 카운트가 만료해도 배수가 남아 있으면 HUD를 유지한다. 개인별 공격속도 중첩과 HIT 수는 별도다.

검증: 증가·상한·이동 초기화·이전 투사체 제외·대상 소실 유예·카운터 만료·공격 시간 고정 자동 테스트 6개 통과. MoveTuning 플레이 모드에서 25명 최대 상태의 Buff 표시와 이동 시 전체 비활성화를 확인했다.
