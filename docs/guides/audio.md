# 게임 사운드 연결

Project 창에서 `Assets/Data/Audio/SoundDatabase.asset`을 열고 재생할 항목의 **Clip** 칸에 AudioClip을 넣는다. 각 항목의 **Volume**은 음량, **Pitch**는 재생 속도와 음높이를 조절한다. BGM의 **Loop**는 기본으로 켜져 있다.

| 목록 | ID | 재생 시점 |
| --- | --- | --- |
| Bgm | `bgm.stage3` | 메인 메뉴 진입 또는 복귀 시 `main bgm.mp3` 재생 |
| Bgm | `bgm.stage` | 1스테이지 진입 시 `stage1.mp3` 재생 |
| Bgm | `bgm.stage2` | 2스테이지 진입 시 `stage2.mp3` 재생 |
| Bgm | `bgm.boss` | 3스테이지(보스) 진입 시 `stage3_boss.mp3` 재생 |
| Sfx | `squad.revive` | 구조 동작 막바지에 동료가 일어설 때 |
| Bgm | `bgm.victory` | 서리기사 클리어 화면에서 전투 BGM을 즉시 끄고 `Victory in Ash.mp3`를 한 번 재생 |
| Sfx | `squad.defeat` | 분대 전멸 |

게임 씬의 **Stage Run → Stages → Bgm Id**에서 각 스테이지의 곡을 지정한다. 이어하기와 재시도도 해당 스테이지의 설정을 사용한다.

`squad.revive`는 뼈가 모여 조립되는 소리를 재생한다. `squad.defeat`는 전멸 시 재생한다. 추가한 효과음은 분대(`squad.*`), 적(`enemy.*`), 보스(`boss.*`)로 구분하며 게임 코드에서 데이터베이스와 같은 ID로 호출한다.

```csharp
using BoneSquadKiting.Audio;

// 게임플레이 컴포넌트의 메서드 안에서 호출한다.
SoundManager.Current.PlaySfx("squad.revive");
SoundManager.Current.PlayBgm("bgm.boss");
SoundManager.Current.StopBgm();
```

메인 메뉴와 게임 씬에는 `Assets/Resources/Audio/SoundManager.prefab`이 배치되어 있다. 씬을 바꿔도 처음 시작한 매니저가 계속 재생한다. 1·2스테이지에서는 열린 워프에 닿는 순간 다음 곡으로 0.5초간 크로스페이드한다. 클리어 화면에서 다음 버튼이나 Enter를 눌러도 같은 곡이 이어진다. 메인 메뉴에 돌아갈 때는 메뉴 곡으로 크로스페이드한다. 전멸 시에는 음악이 페이드아웃된다. 같은 곡을 처음부터 다시 들으려면 `PlayBgm(id, restart: true)`를 호출한다.

효과음은 프리팹의 **Sfx Pool → Max Voices** 개수까지 겹쳐 재생한다. 기본값은 16개이며 모두 사용 중이면 순서대로 한 자리를 재사용한다. 음악과 효과음의 전체 음량은 `Assets/Data/Audio/SoundMixer.mixer`의 BGM·SFX 그룹에서 조정한다.

## 전투 효과음의 재생 시점

| 동작 | 효과음 ID | 기준 |
| --- | --- | --- |
| 석궁 발사 | `squad.crossbow.fire` | 병사의 상체 사격 클립 8프레임(30fps)에 `AttackRelease`가 대기 중인 화살을 발사할 때. 분대장의 창은 제외한다. |
| 화살 명중 | `squad.arrow.hit.armor`, `squad.arrow.hit.humanoid` | 화살이 살아 있는 잡몹이나 미니 보스에 닿을 때 한 종류를 고른다. **Armored**를 켠 적(투석기·투창병)은 금속음, 나머지는 둔탁한 명중음이다. 마력의 주인은 석궁 화살이 실제 체력을 깎으면 투석기와 같은 금속음을 낸다. |
| 분대원 피격 | `enemy.grunt.hit`, `enemy.caster.hit` | 웨이브 근접병의 공격과 원거리병의 보라색 에너지볼이 분대에 피해를 줄 때 각각 전용 녹음을 재생한다. |
| 진형·피격 | `squad.formation.command`, `squad.hit.bones` | Q·W·E·R로 진형을 전개하면 `전형변경시 효과음.mp3`가 한 번 재생된다. 피해를 받아 병사가 쓰러지는 순간에는 뼈가 흩어지는 소리가 난다. |
| 부활 | `squad.revive.magic`, `squad.revive` | 부활을 시작하면 시전자의 마력음이 난다. 진행률 84%에서 두 병사가 일어서는 동작에 맞춰 두 번째 효과음이 난다. 그 전에 시전자가 쓰러지면 두 번째 효과음은 생략한다. |
| 잡몹 등장 | `stage.wave.start` | 일반 웨이브, 돌발 무리, 성문 후방 증원이 실제로 등장할 때 `스폰소리.mp3`가 무리당 한 번 들린다. |
| 불마법사 | `enemy.firemage.scorch`, `enemy.firemage.eruption` | 장판이 보이기 시작할 때 그을림, 장판이 발동할 때 분출. 병사가 피했어도 들린다. |
| 투창 | `enemy.javelin.shout`, `enemy.javelin.flight` | 일반 투창병은 투척 클립의 8프레임(30fps)에 기합·비행음·투사체가 함께 나간다. 모델이 없는 창투척 미니 보스는 W 양옆 띠 장판의 시전 시작을 기준으로 삼는다. |
| 투창 분열·착지 | `enemy.javelin.split`, `enemy.javelin.impact` | 창투척 미니 보스 W의 마지막 경고 구간에 분열음, 양쪽 띠의 피해 판정에 착지음이 난다. 일반 투창병의 직선 투사체에는 분열음이 없다. |
| 투석기 | `enemy.catapult.launch`, `enemy.catapult.flight`, `enemy.catapult.impact` | Fire 클립의 0.575초 이벤트에 나무 팔 소리가 난다. 돌이 팔을 떠날 때 비행음, 목표 지점에 닿아 파편이 튈 때 충돌음이 난다. |

투창 미니 보스의 W는 게임에서 양옆 띠 장판으로 표현한다. 분열하는 창 모델이 없어 분열음을 마지막 경고에 맞췄다. 석궁은 첫 화살이 떠나는 순간부터 0.12초 안에 실제로 발사된 화살을 한 소리로 묶는다. 한 발은 원래 볼륨의 30%로 시작하고 발사 수에 따라 로그 곡선으로 최대 90%까지 커진다. 매 일제 사격과 분대장의 별도 투창마다 피치는 0.9~1.1 사이에서 달라진다. 동일한 명중음의 재생 간격은 0.06초다.

효과음의 **Start Offset**은 원본 앞의 무음을 건너뛰는 시간(초)이다. Unity가 디코딩한 MP3에서 측정한 앞 무음에 맞춰 진형 변경음은 0.035초, 보스 준비음과 방출음은 각각 0.062초, 전멸기 충돌음은 0.055초를 건너뛴다.

## 마력의 주인 보스전

| 공격 | 소리가 나는 순간 |
| --- | --- |
| 원형 낙검 | 낙검 연출 시작 후 1.15초에 공중의 검이 보이며 소환음이 난다. 1.39초부터 낙하음이 나고, 1.51초에 지면에 닿으면 낙하음을 끊고 충돌음을 낸다. |
| 평행 참격 | 왕좌에서 검을 소환할 때 소환음이 난다. 경고가 끝나고 두 줄의 검기가 출발할 때 비행음이 한 번 난다. |
| 가로 차징 | 검을 모으는 자세에서 `검기&전멸기준비.mp3`가 한 번 재생된다. 세 줄의 검기가 나가는 프레임에 `검기방출.mp3`가 한 번 재생된다. |
| 즉사 내려찍기 | 보스가 모습을 드러내 검을 들어 올릴 때 검기와 같은 준비음이 난다. 칼이 바닥에 닿는 판정에 `전멸기 지면충돌.mp3`가 한 번 재생된다. 분대가 피해도 충돌음은 들린다. |
| 순간이동 | 보스가 사라질 때 `보스순간이동소리.mp3`가 한 번 난다. 기립 뒤와 검기 방출 뒤의 순간이동도 포함한다. |
| 그로기 | 2페이즈의 연속 공격을 마치고 그로기에 들어가는 순간 `보스 그로기소리.mp3`가 한 번 난다. |

기상·기절·기립·사망에도 각각의 전용 클립을 쓴다.
