# 맵 제작 안내 (아티스트용)

> 대상: 스테이지 맵을 만드는 아티스트.
> 기준 코드: `bone-squad-kiting/Assets/Scripts/Stage/WalkGridBaker.cs` (main `128cc8d`).
> 최종 갱신: 2026-11-18. 아직 구현 전이라 이 문서에 없는 것: 시작 지점·끝 지점 표시 방법, 외곽선으로 이동 가능 범위를 지정하는 방법(결정 #29). 구현되면 추가한다.

## 한 줄 요약

**바닥에는 Ground 레이어, 길을 막는 것에는 Obstacle 레이어.** 두 가지만 지키면 분대가 갈 수 있는 곳과 적이 찾아오는 길이 자동으로 정해진다. 베이크 버튼은 없다. 맵을 고치면 다음 플레이에 바로 반영된다.

## 게임이 맵을 읽는 방식

스테이지가 시작될 때 게임이 맵을 0.75 크기의 칸으로 나누고, 칸마다 위에서 아래로 선을 쏜다.

- 선이 **Ground 레이어의 콜라이더**에 닿고,
- 그 지점 근처(0.3 이내)에 **Obstacle 레이어의 콜라이더**가 없으면

그 칸은 **이동 가능**이다. 나머지는 전부 이동 불가다. 분대의 이동 경계와 적의 길찾기가 이 결과 하나를 같이 쓴다.

게임이 보는 것은 **콜라이더와 레이어**뿐이다. 눈에 보이는 메시만 있고 콜라이더가 없으면 게임은 그 오브젝트를 모른다.

## 작업 규칙

### 1. 걸을 수 있는 바닥

지면은 **Unity 터레인**으로 만든다(결정 #29).

- 터레인 오브젝트의 레이어를 **Ground**(7번)로 바꾼다. 터레인에는 콜라이더가 이미 붙어 있다.
- **플레이 영역은 높이 0으로 평평하게** 둔다. 유닛과 적은 높이 0의 평면 위에서 움직이므로, 언덕을 만들면 유닛이 땅에 파묻히거나 뜬다. 플레이 영역 바깥은 자유롭게 조형해도 된다(절벽, 산, 구덩이).
- 터레인은 큰 사각형 한 장이라 그대로 두면 **전체가 이동 가능**이 된다. 갈 수 없는 곳은 아래 2번·5번이나 외곽선(구현 예정)으로 막아야 한다.
- 터레인에 페인팅한 나무와 풀은 길을 막지 못한다. 길을 막을 나무는 프리팹으로 따로 배치하고 2번 규칙을 따른다.

터레인이 아닌 바닥 오브젝트를 쓸 때:

- 콜라이더를 붙인다(`MeshCollider` 또는 `BoxCollider`).
- 레이어를 **Ground**(7번)로 바꾼다.
- 바닥은 **평평하게, 높이 0에** 둔다. 유닛과 적은 높이 0의 평면 위에서 움직인다. 언덕이나 계단을 만들어도 유닛은 올라가지 않는다.

### 2. 길을 막는 것 (벽, 바위, 나무 기둥 등)

- 콜라이더를 붙인다.
- 레이어를 **Obstacle**(8번)로 바꾼다.
- 콜라이더가 **바닥에 닿아 있어야** 막힌다. 게임은 바닥 근처만 검사하므로, 공중에 떠 있는 것(나뭇가지, 아치 윗부분)은 막지 않는다.

### 3. 지나갈 수 있는 장식

- 레이어를 바꾸지 않는다(Default 그대로). 풀, 작은 돌, 바닥 무늬 등.

### 4. 바닥이 없는 곳

- Ground 콜라이더가 없는 곳은 자동으로 이동 불가다. 구멍이나 맵 바깥을 따로 막을 필요가 없다.

### 5. 보이지 않는 경계

- 빈 오브젝트에 `BoxCollider`만 붙이고 레이어를 **Obstacle**로 한다. 렌더러는 필요 없다.
- 바닥은 이어져 있는데 못 가게 하고 싶은 곳에 쓴다.

### 6. 씬에 WalkGridBaker 하나 두기

- 빈 오브젝트를 만들어 `WalkGridBaker` 컴포넌트를 붙이고 **맵 중앙**에 둔다.
- **Size**(x, z)가 플레이 영역 전체를 덮게 한다. Scene 뷰에 흰 테두리 상자로 보인다. 상자 밖은 전부 이동 불가가 된다.
- **Ground Mask** = Ground, **Obstacle Mask** = Obstacle.
- 나머지 값은 그대로 둔다(Cell Size 0.75, Clearance 0.3). 바꿔야 할 것 같으면 프로그래머에게 먼저 말한다. Cell Size는 적 이동 코드와 맞물려 있다.

## 결과 확인하기

`WalkGridBaker` 오브젝트를 선택하면 Scene 뷰에 칸이 그려진다.

- **초록** = 이동 가능
- **빨강** = 이동 불가

맵을 만들면서 수시로 선택해서 본다. 플레이를 누르지 않아도 보인다.

## 치수 기준

| 항목 | 값 | 설명 |
| --- | --- | --- |
| 칸 크기 | 0.75 | 이보다 얇은 벽이나 틈은 칸에 걸리지 않을 수 있다 |
| 통로 최소 폭 | 1.5 (2칸) | 1칸짜리 통로는 적이 대각선으로 못 지나가 막힌다 |
| 분대가 지나가는 통로 권장 폭 | 8 이상 | 원형 진형 지름이 약 7.4다. 좁으면 일자 진형으로만 지나갈 수 있다. 의도한 좁은 길이 아니면 넉넉하게 |
| 벽 두께 | 0.75 이상 | 얇으면 칸 사이로 빠져 구멍이 생길 수 있다 |
| 참고: 지금 보스 아레나 | 24.6 × 20.4 | 전투가 벌어지는 넓은 공간의 기준 |

## 자주 나는 실수

| 증상 | 원인 |
| --- | --- |
| 전부 빨강이다 | 바닥에 콜라이더가 없거나, 레이어가 Ground가 아니거나, `WalkGridBaker`의 Ground Mask가 비어 있다 |
| 벽이 있는데 초록이다 | 벽에 콜라이더가 없거나, 레이어가 Obstacle이 아니거나, 콜라이더가 바닥에서 떠 있다 |
| 맵 일부가 통째로 빨강이다 | `WalkGridBaker`의 Size가 그 부분을 덮지 못한다 |
| 통로가 군데군데 빨강으로 끊긴다 | 통로가 너무 좁다. 벽에서 0.3 안쪽 칸은 막힌 것으로 본다 |
| 장식을 놓았더니 길이 막혔다 | 장식의 레이어가 Obstacle로 되어 있다 |

## 맵을 넘길 때 확인할 것

- [ ] 시작 지점에서 끝 지점까지 초록 칸이 끊기지 않고 이어진다
- [ ] 초록이면 안 되는 곳(벽 안쪽, 맵 바깥)에 초록이 없다
- [ ] 분대가 지나가야 하는 길의 폭이 의도한 대로다
- [ ] 바닥이 높이 0에 평평하게 있다
