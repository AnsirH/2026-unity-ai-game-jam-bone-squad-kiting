# 적 투사체 감속과 페이드

`MobDefinition`의 Shot Lifetime을 0보다 크게 설정하면 수명 기반 투사체가 된다.
Shot Speed Curve는 정규화한 수명(0~1)에 대한 Shot Speed 배율이다.
Shot Fade Start는 전체 외형이 사라지기 시작하는 수명 비율이다.
Lifetime이 0인 기존 적은 기존의 일정 속도·거리 제한 동작을 유지한다.

Thrower는 수명 1.5초, 시작 속도 0.6배, 10% 지점에서 1.5배로 가속 후
마지막에 0배로 감속한다. 55% 지점부터 전체 페이드한다.
창 본체의 URP Lit 머티리얼은 런타임 복제본만 투명 렌더링으로 바꾼다.
트레일과 파티클을 포함한 자식 렌더러의 색상도 함께 줄인다.
풀 재사용 시 원래 색으로 복원하며 원본 에셋 머티리얼은 수정하지 않는다.

충돌·벽 접촉은 기존처럼 즉시 투사체를 반환한다. 수명 기반 비행의 감속·페이드는
맞지 않고 계속 날아가는 경우에 적용된다.
