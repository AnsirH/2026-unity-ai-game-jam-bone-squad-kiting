# 웨이브 세팅 안내

> 대상: 웨이브를 세팅하고 테스트하는 사람.
> 기준 코드: sub-1 `cdd0098` 시점의 `Assets/Scripts/Data/WavePlan.cs`, `Stage/WaveSpawner.cs`, `Assets/Editor/WaveToolWindow.cs`.
> 최종 갱신: 2026-11-18 밤. 자동 테스트(EditMode 149, PlayMode 160)는 통과했고 도구 창이 뜨는 것까지 확인했다. 실제로 플레이하며 써 본 것은 아니다.
> 설계 배경: `docs/plans/2026-11-18-wave-tool-design.md`.

## 한눈에 보기

- 한 스테이지의 웨이브 설정은 **파일 하나**(웨이브 플랜)다. 위치: `Assets/Data/Waves/<스테이지>/Stage1_v01.asset`.
- **파일 하나가 버전 하나**다. 새 버전은 복제해서 만들고 지난 버전은 지우지 않는다.
- 스테이지는 그중 하나를 가리킨다. 가리키는 파일을 바꾸면 버전이 바뀐다.
- 도구 창: 메뉴 **BoneSquadKiting → Wave Tool**.

## 웨이브 플랜의 내용

| 칸 | 뜻 |
| --- | --- |
| Note | 이 버전에서 무엇을 바꿨는지. 도구 창의 버전 목록에 보인다 |
| First Wave Delay | 시작 후 첫 웨이브까지의 시간(초) |
| Blend | 끔: 구간의 값이 다음 구간이 시작될 때까지 그대로. 켬: 다음 구간의 값으로 서서히 바뀜 |
| Sections | 구간 목록(아래) |
| Bursts | 돌발 무리 목록(아래) |
| Min / Max Spawn Distance | 적이 나타나는 거리(분대 중심 기준). 화면 밖이 되도록 잡는다 |
| Ahead Share | 끝 지점 쪽에서 오는 비율(0~1) |
| Group Size / Group Spread | 한 무리의 마리 수와 퍼지는 반경 |

**구간(Sections)** — 한 줄이 구간 하나다.

| 칸 | 뜻 |
| --- | --- |
| From Progress | 분대가 여기까지 오면 이 줄을 쓴다. 0 = 시작 지점, 1 = 끝 지점 |
| Interval | 웨이브 사이의 시간(초). 최소 0.5 |
| Mobs | 한 웨이브의 구성. 잡몹 종류와 마리 수를 여러 줄 넣을 수 있다 |

- 진행도는 **가장 멀리 간 지점** 기준이다. 뒤로 물러나도 쉬워지지 않고, 멈춰 있으면 같은 구간의 주기로 계속 나온다.
- 첫 구간의 From Progress를 0보다 크게 두면 그 전까지는 웨이브가 없다.
- 줄의 순서는 상관없다(From Progress로 판단한다).

**돌발(Bursts)** — 분대가 그 진행도에 **처음 닿는 순간 한 번** 나오는 무리. 주기와 무관하다.

## 도구 창 쓰는 법

1. 테스트할 스테이지 씬을 연다(`Assets/Scenes/Stage1.unity` 등).
2. **BoneSquadKiting → Wave Tool**을 연다. 위쪽에서 스테이지를 고른다.
3. 왼쪽 목록에서 버전을 고른다. ▶ 표시가 열린 씬이 지금 쓰는 버전이다.

| 버튼 | 하는 일 |
| --- | --- |
| 이 버전으로 플레이 | 열린 씬이 이 버전을 쓰게 한다. 씬이 수정된 상태가 되므로 **Ctrl+S로 씬을 저장**해야 남는다 |
| 복제해서 새 버전 | 번호를 하나 올린 사본을 만든다(`_v02` → `_v03`). Note에 무엇을 바꿀지 적는다 |
| Project 창에서 보기 | 그 파일을 Project 창에서 가리킨다 |

오른쪽에서 고른 버전을 바로 편집한다. 값을 고친 뒤 **Ctrl+S**를 눌러야 파일에 저장된다.

**요약 표** — 구간마다 계산한 값.

| 열 | 뜻 |
| --- | --- |
| 주기(초), 한 웨이브 구성 | 그 구간의 설정 |
| 분당 마리 | 구성 합계 ÷ 주기 × 60 |
| 분당 체력 합 | 분당 마리 × 잡몹 체력. 분대 화력과 비교하는 기준 |

**비교** — "비교할 버전"에서 다른 버전을 고르면 각 칸이 `지금 버전 ← 비교 버전`으로 나오고, 달라진 줄이 주황색이 된다.

## 플레이하면서 테스트하기

플레이 중에 도구 창 위쪽에 "플레이 중" 상자가 나타난다.

| 기능 | 설명 |
| --- | --- |
| 상태 줄 | 버전 이름, 진행도, 현재 구간, 웨이브 수, 다음 웨이브까지, 살아 있는 잡몹, 누적 등장 수 |
| 지금 웨이브 한 번 | 현재 구간의 웨이브를 즉시 부른다 |
| 웨이브 멈춤 | 주기를 세운다. 다시 누르면 이어진다 |
| 잡몹 전부 제거 | 화면의 잡몹을 지운다 |
| 배속 | 0.5× / 1× / 2× / 3× |

- **플레이 중에 값을 고치면 다음 웨이브부터 적용된다.** 에셋이라 플레이를 꺼도 고친 값이 남는다(Ctrl+S로 저장).
- 플레이 중에 "이 버전으로 플레이"를 누르면 다음 웨이브부터 그 버전으로 바뀐다. **이 전환은 이번 플레이에만 적용된다.** 계속 쓰려면 플레이를 끈 뒤 다시 누르고 씬을 저장한다.
- 게임 화면의 F1 정보창에도 버전 이름, 구간, 다음 웨이브까지, 누적 등장 수가 나온다.

## 버전을 나누는 순서 (권장)

1. 지금 버전을 "복제해서 새 버전"으로 복제한다.
2. Note에 바꿀 내용을 적는다. 예: `v03: 0.5 구간 주기 7 → 5`.
3. 값을 고치고 Ctrl+S.
4. "이 버전으로 플레이"를 누르고 씬을 저장한 뒤 플레이한다.
5. 이전 버전과 "비교할 버전"으로 숫자를 본다.

## 아티스트 맵 씬에서 쓰기

맵 표식 방식(Stage Start)으로 만든 씬은 **Stage Start의 Wave Plan 칸**에 웨이브 플랜 파일을 넣으면 웨이브가 나온다. 비워 두면 웨이브가 없다.

- 진행도는 시작 지점에서 **End Point**까지의 길로 잰다. End Point가 없으면 진행도가 0에 머물러 첫 구간만 쓰인다.
- 도구 창의 "이 버전으로 플레이"는 이 칸도 바꿔 준다.

## 알아둘 점

- 잡몹 종류는 지금 `Assets/Data/Mobs/Grunt.asset` 하나다. 원거리 몹은 아직 없다. 종류가 생기면 구성에 줄을 추가하면 된다.
- 동시에 살아 있는 잡몹은 `GameTuning.asset`의 **Mob Max Alive**(지금 200)를 넘지 못한다. 넘으면 그 웨이브는 잘린다.
- 미니 보스는 웨이브 플랜에 넣지 않는다. 맵 위의 표식으로 놓는다. 스테이지의 마지막 미니 보스가 죽으면 웨이브가 멈춘다(결정 #42·#46).
- `Stage1~4_v01`은 예전 곡선 값을 네 구간으로 옮긴 것이다. 재미를 확인한 값이 아니다.
- 스테이지 씬을 생성 도구로 다시 만들어도 그 씬이 쓰던 버전은 유지된다.
- 아직 없는 것: 무적, 진행도를 지정해서 시작하기, 플레이 기록(버전별 결과 비교).
