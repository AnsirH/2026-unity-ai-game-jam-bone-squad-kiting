# 허한결 (`ansirh`) 현재 상태

> 본인 또는 본인의 AI만 고친다. 레포에 올라가 팀이 함께 본다. 지난 작업은 쌓지 말고 최근 상태만 남긴다.

## 완료

- 보스 아레나(M1): 분대 이동, 평타·투사체, 보스 패턴, 입력(우클릭·어택땅·Q/W/E/R 진형·휠 회전·S 정지·F 부활), HUD, 연출
- 규칙: 유닛은 멈춘 상태에서만 사격, 공격 오더는 분대 사거리에서 정지
- 맵: 이동 가능 범위(지면 레이캐스트, 외곽선), 시작·끝 지점, 잡몹 Flow Field 길찾기, 진행도 곡선 웨이브
- 분대 경계 보완(벽 우회, 눌린 유닛 고르게 배치, 사선 경계), 부활, 분대장
- 미니 보스: 위치 표식, 등장·사망 연출, 정의 5종, 고정 대포, 처치 시 활성화 조건
- 스테이지 5개 연결(Stage1~4 + Arena)과 Windows 시험 빌드
- 테스트: EditMode 133개, PlayMode 132개 통과

## 막힘

- 시험 빌드를 실행해서 플레이해 보지 않았다. 셰이더가 빌드에서 제대로 나오는지 확인되지 않았다
- 잡몹 200마리일 때의 프레임, 모델로 교체한 뒤의 프레임을 재지 않았다
- Stage1~4는 전부 임시 직선 통로이고 수치는 임의의 초기값이다. 기획의 지형(V자, 성벽)은 아티스트 맵이 와야 반영된다
- 미니 보스 5종이 화면에서 똑같이 보인다(임시 원기둥). 여러 마리일 때 상단 체력 바는 첫 번째 것만 보여 준다
- 보스 바로 옆에서는 원형 진형 일부가 진입 금지 구역에 눌려 중앙 폭발에 맞을 수 있다
- 올라온 모델의 애니메이션 상태 이름이 예상과 다르고(Fire, Soldier_Fire_SlowRun, Spear_Walk) Die가 없다
- 원거리 소형 몹은 설계와 구현이 없다
- 결정 #14~#47은 ansirh가 정했거나 기획자 문서를 전달한 것이다. 팀 공유 상태는 기록되지 않았다
- 맵 제작 안내(`docs/guides/map-authoring.md`)에 미니 보스 표식, 씬 연결(Build Settings·Next Scene), 스크린샷이 없다
