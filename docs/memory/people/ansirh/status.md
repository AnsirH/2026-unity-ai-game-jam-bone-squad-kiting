## 완료

- 게임 로직 전부: 분대 이동, 평타·투사체, 보스 패턴, `GameDirector`, 입력(우클릭 스마트 커맨드·어택땅·Q/W/E/R 진형·휠 회전)
- 규칙: 유닛은 멈춘 상태에서만 사격, 공격 오더는 분대 사거리에서 정지, 사거리 두 개는 인스펙터에서 조절
- 진형: 살아 있는 인원수만큼 원점에서 바깥으로 채움, 가까운 슬롯 재배정, 원형 반경과 중앙 폭발이 인원수에 비례해 축소
- 아레나 씬: 원근 쿼터뷰(60°, FOV 30°), 화면 가장자리 스크롤 카메라, 임시 비주얼, 장판 표시
- HUD(uGUI)와 F1 테스트 정보창, 연출(셰이크·플래시·파티클·링)
- 테스트: EditMode 113개, PlayMode 46개 통과(실제 씬 플레이, 전체 경기 자동 플레이 포함)

## 막힘

- 마우스·키보드 조작감, 연출 세기, 카메라 스크롤은 사람이 직접 플레이해서 확인해야 한다
- 사거리 두 값(둘 다 15.9)과 휠 한 칸당 회전 각도(15°)는 임시값. 지금 값으로는 어택땅을 찍어도 분대가 움직이지 않는다
- 플레이어 빌드를 아직 한 번도 만들어 보지 않았다
- sub-1 브랜치의 최신 문서(스테이지 구조, 마감·부활·맵 결정 #18~#26)는 아직 main에 병합되지 않았다
