# 용어

> 팀 안에서 같은 말을 같은 뜻으로 쓰기 위한 표. 화면 문구·문서·코드 이름이 다르면 함께 적는다.

| 용어 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 분대 중심 (anchor) | 진형의 원점. 이동 명령의 목적지로 걸어가는 점이고 유닛은 `분대 중심 + 슬롯`을 따라간다. 코드 `FormationController.Anchor` | 진영 |
| 진형 | 분대 중심 기준 유닛 25명의 배치 규칙(밀집·일자·원형 등). 코드 `FormationDefinition` | 진영, 대형 |
| 진형 회전 | 마우스 휠로 분대 중심을 축으로 진형을 돌리는 조작. 휠 아래 = 시계 방향 (결정 #16) | |
| 이동 명령 | 우클릭 지면. 순수 이동이고 이동 중에는 쏘지 않는다. 코드 `OrderKind.Move` | |
| 어택땅 | A + 좌클릭. 지점으로 가다가 적이 분대 사거리 안에 들어오면 멈춰서 쏜다. 코드 `OrderKind.AttackMove` | 공격 이동 |
| 타겟 공격 | 우클릭으로 적을 지정. 그 적만 쏜다. 코드 `OrderKind.AttackTarget` | |
| 유닛 사거리 | 유닛 한 명이 쏠 수 있는 거리. 유닛 위치 기준 | 사거리(구분 없이) |
| 분대 사거리 | 분대 중심 기준 거리. 어택땅·타겟 공격 분대가 멈추는 기준 (결정 #17) | |
| 잡몹 | 보스가 아닌 다수의 약한 적. M2에서 최대 200마리 | 몹, 쫄 |
| 장판 | 보스 패턴의 위험 구역. 예고 뒤 그 안의 유닛이 피해를 입는다. 코드 `DangerShape` | |
| 가장자리 스크롤 | 마우스 커서를 화면 가장자리에 대면 카메라가 그 방향으로 이동하는 조작 (결정 #20) | |
