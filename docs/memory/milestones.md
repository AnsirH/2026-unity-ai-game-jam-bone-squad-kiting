## 현재 단계

**스테이지 5개가 이어지는 상태에서 내용 채우기와 비주얼 교체 단계.** 마감: 2026-11-19 08:00 빌드 · 10:00 코드 프리즈 · 14:00 제출.

전체 구조(결정 #37·#45·#46): 스테이지 5개. 1·2·4는 잡몹 + 미니 보스를 모두 처치한 뒤 끝 지점, 3은 미니 보스가 나오지만 다 잡을 수 없게 몰려오는 적을 뚫고 끝 지점 도달, 5는 보스. 기획자의 스테이지 구성과 미니 보스 5종: `docs/plans/2026-11-18-stage-lineup.md`.

**구현된 것**(구현 세션 보고 기준, 2026-11-18 밤. 사람의 플레이 확인 전):

- 보스 아레나(M1), 이동 가능 범위·외곽선·시작/끝 지점, 잡몹과 진행도 곡선 웨이브, 유도 투사체
- 분대 경계 보완(결정 #36), 부활(#27·#38), 분대장(#39~#41), 미니 보스와 등장·사망 연출(#37·#42)
- 스테이지 전환: 씬 Stage1~4 + Arena, 클리어 시 다음 씬, 25명 초기화, 전멸 시 재시도
- 미니 보스 정의 5종, 처음부터 놓인 고정 대포, 다른 미니 보스 처치 시 활성화, 공격 간격 무작위, 연출·전멸은 마지막 한 마리만
- Windows 시험 빌드 성공(오류 0). 실행해서 플레이해 본 것은 아님
- 테스트: EditMode 133 · PlayMode 132 통과

**남은 것:**

1. 회전하는 장판 2종(한 번 터짐 / 지속 피해)과 진형 최대 회전 속도 값(결정 #47)
2. 지역 잠금: 대포를 잡기 전에는 카메라가 다음 지역으로 넘어가지 않음(결정 #46·#47)
3. 3스테이지 마지막의 공격 간격 가속
4. 비주얼 교체 구조: 프리팹 칸과 아트 세트 → 이펙트 → 애니메이션(결정 #43·#44, `docs/plans/2026-11-18-visual-swap-design.md`). 아티스트의 병사·분대장 모델이 원격 main에 올라와 적용 시도 중
5. 아티스트 맵으로 임시 통로 씬 교체, 스테이지별 배치와 수치 조정
6. 빌드를 실행해 플레이 확인, 최종 빌드(07:00부터)

정해지지 않은 것: 원거리 소형 몹(적 투사체가 새로 필요), 미니 보스 종류별 수치, 진형 최대 회전 속도 수치(ansirh가 플레이하며 정함).

시간이 부족하면 잘라낼 것: 원거리 소형 몹, 회전하는 장판, 예약 피해, 클릭 판정 교체, 화면 문구 영어화. 맵이 늦으면 한 맵을 여러 스테이지에 재사용한다.
