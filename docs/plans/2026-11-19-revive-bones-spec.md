# 부활 뼈 연출 구현 계획

## 목표

플레이어가 전투 화면에서 어느 아군의 부활이 곧 끝나는지, 그 몸이 어디에서 일어날지 알아볼 수 있게 한다. 부활 한 건을 뼈 세 개의 움직임으로 보여준다.

## 확정된 동작

| 시점 | 화면에서 보이는 동작 |
| --- | --- |
| 부활 시작 | F로 시전자 한 명과 전사자 한 명이 짝지어지면 해당 부활 진행률 0%에 부러진 뼈, 25%에 척추뼈, 50%에 어깨뼈가 차례로 화면 밖에서 출발한다. 각 조각은 전체 차징 시간의 13% 동안 회전하며 곡선을 따라 날아온다. 궤도에 닿을 때에는 목표 위치를 살짝 지나쳤다가 부드럽게 자리를 잡는다. 세 조각 모두 상아색 표면과 초록 프레넬 테두리를 갖는다. |
| 차징 | 세 뼈가 아군 허리 높이에서 분대 중심을 따라 돈다. 일자 진형은 좁은 반경 1.8, 밀집·원형·십자 진형은 넓은 반경 3.2를 쓴다. 차징 중 진형을 바꾸면 반경이 부드럽게 변한다. |
| 완료 직전과 100% | 75%부터 궤도가 잠깐 바깥으로 부푼다. 84%부터 세 조각이 빠르게 안쪽으로 당겨져 99%에 해당 아군의 출현 지점에 모여 멈춘다. 100%에서 뼈가 사라질 때 해당 아군 한 명이 그 자리에서 온전한 체력으로 일어나 빈 진형 자리로 이동한다. |
| 동시 부활 | 부활마다 세 조각을 따로 표시한다. 두 건은 각자의 진행률에 맞춰 한 조각씩 출발하므로 동시에 최대 여섯 조각이 보인다. 두 무리가 같은 분대 중심을 조금 다른 각도로 돌다가 각각 자기 출현 지점으로 수렴한다. |
| 시전자 사망 | 취소된 건에서 이미 출발한 뼈만 현재 위치에서 초록빛을 잃고 사라진다. 아직 순서가 오지 않은 뼈는 등장하지 않는다. 해당 대상은 전사 상태로 남고 다른 무리의 공전과 부활은 이어진다. |

차징 초반에는 궤도에 합류한 뼈의 수로, 세 조각이 모두 모인 뒤에는 궤도가 벌어졌다가 출현 지점으로 좁혀지는 모습으로 진행률을 읽는다. 한 건에 등장하는 최대 조각 수는 세 개다. 현재 부활 시간은 3초이며 실제 값은 `GameTuning.asset`의 `ReviveSeconds`를 따른다.

## 구현 할 일

아래 경로는 유니티 프로젝트 루트 기준이다.

- [x] **출현 지점을 공유한다.** `Assets/Scripts/Squad/ReviveSystem.cs`의 `TryStart`에서 부활 건마다 출현 방향과 상대 위치를 정한다. 뼈가 수렴할 때와 아군이 일어날 때 모두 현재 분대 중심에 같은 상대 위치를 더한다. 출현 반지름은 `Assets/Data/GameTuning.asset`의 0.6이다.
- [x] **세 조각에 초록 프레넬을 입힌다.** 공용 아트 세트가 `Assets/Art/Prefab/BoneFragments/`의 `BrokenBone`, `Vertebra`, `Scapula`를 하나씩 참조한다. 각 재질은 기존 텍스처와 `MobPBR` 셰이더의 프레넬을 사용한다.
- [x] **부활마다 진입·공전·수렴을 재생한다.** `SquadView`가 자기 분대의 디렉터를 `Assets/Scripts/Fx/ReviveBoneFx.cs`에 연결한다. 세 조각은 해당 시전자의 실제 진행률에 맞춰 서로 다른 시점에 전투 카메라의 화면 밖에서 출발한다. 날아오는 동안의 회전과 공전 반경은 각 조각의 진입 시점과 현재 진형에 맞춘다.
- [x] **완료·취소·재시작을 구분해 정리한다.** `ReviveCompleted`는 해당 세 조각을 몸의 출현 좌표에 모아 회수한다. `ReviveCancelled`는 그때까지 출발한 조각만 소등해 사라지게 하고 이후 조각의 진입을 중단한다. 진행 목록이 비거나 시스템이 새로 생성되면 이전 뼈를 정리한다. 부활음과 완료 입자는 기존 완료 이벤트에서 재생한다.

## 플레이 검증 기준

기존 부활 규칙은 `Assets/Tests/PlayMode/ReviveTests.cs`로 확인하고, 궤도와 출현 위치는 실제 전투 카메라에서 확인한다.

| 상황 | 기대 결과 |
| --- | --- |
| 전사자 1명, F 한 번 | 3초 설정에서 0초·0.75초·1.5초에 한 조각씩 출발해 각각 0.39초 동안 날아온다. 2.25초부터 궤도가 벌어지고 2.52초부터 안쪽으로 당겨져 2.97초에 멈추면, 3초에 한 명이 같은 자리에서 일어난다. |
| 전사자와 시전자가 각각 2명 이상, 0초와 1초에 F | 현재 3초 설정에서 2.5초에 두 번째 무리의 마지막 뼈가 출발하면 총 여섯 조각이 출발한 상태다. 3초째 첫 아군이 일어날 때 두 번째 무리는 남고, 4초째 두 번째 아군이 일어난다. |
| 두 건 중 한 시전자만 차징 중 사망 | 두 번째 조각이 출발하기 전에 취소하면 첫 조각만 빛을 잃고 사라지고, 나머지 두 조각은 나타나지 않는다. 취소된 대상은 전사 상태이고, 다른 한 명은 예정된 시각에 부활한다. |
| 차징 중 이동·진형 변경·일시정지 | 궤도는 분대 중심을 따라간다. 원형 진형에서도 기준은 분대 중심이다. 일시정지 동안 차징과 연출이 함께 멈추고 재개 후 같은 지점에서 이어진다. |
| 대상이 없는 상태에서 F 또는 차징 중 재시작 | 유효한 부활이 없으면 뼈가 생기지 않는다. 재시작한 분대에는 이전 무리의 뼈가 남지 않는다. |

## 전투 카메라 기준 연출값

뼈 크기는 프리팹의 0.72배다. 공전은 차징 시간당 1.45바퀴 속도이며 마지막 당김에 0.1바퀴를 더 비튼다. 취소되면 이미 나온 조각의 초록빛이 즉시 꺼지고 0.18초에 걸쳐 사라진다. 완료 순간에는 추가 대기 없이 몸이 나타난다.
