# 스테이지 설정 설계: 웨이브, 미니 보스, 연출

> 상태: **설계 제안**. 요구는 ansirh가 정했고(결정 #37~#39), 아래 구조는 제안이다. 구현 세션이 더 나은 방법을 알면 바꿔도 된다.
> 작성: sub-1 세션, 2026-11-18.
> 이 문서는 `2026-11-18-stage-structure-design.md` §0의 "진행도 곡선" 제안을 대체한다. 수치는 전부 초기값이고 플레이로 확인한 것이 아니다.

## 1. 정해진 것

- 스테이지는 5개다(결정 #37).

| 스테이지 | 구성 | 클리어 |
| --- | --- | --- |
| 1 | 잡몹 + 미니 보스 | 미니 보스를 쓰러뜨린 뒤 끝 지점 도달 |
| 2 | 잡몹 + 미니 보스 | 위와 같음 |
| 3 | 미니 보스 없음. 적이 엄청나게 몰려오는 구간 | 끝 지점 도달 |
| 4 | 잡몹 + 미니 보스 | 미니 보스를 쓰러뜨린 뒤 끝 지점 도달 |
| 5 | 보스 | 보스 처치 |

- 웨이브는 끝없이 나오고, 끝 지점으로 갈수록 더 어렵고 더 자주 온다. 멈춰 있어도 나오지만 주기가 짧아지지는 않는다(결정 #34). 한 자리에서 버티는 플레이는 허용한다.
- **웨이브 설정과 미니 보스 위치 설정이 쉬워야 한다.**
- 미니 보스가 등장할 때와 죽을 때 짧은 연출이 있다.

## 2. 설정 방식: 씬에 놓는 표식

**제안: 웨이브와 미니 보스를 맵 위에 직접 놓는 오브젝트로 설정한다.** 이동 가능 범위를 외곽선으로 그리는 것과 같은 방식이다. 맵을 보면서 "여기서부터 이렇게 나온다", "미니 보스는 여기"를 정할 수 있고 Scene 뷰에 바로 보인다.

앞서 제안한 "진행도에 따른 곡선"은 쓰지 않는다. 곡선은 맵의 어느 지점인지 눈으로 알 수 없고, 굽은 길에서 진행도를 계산하는 코드가 따로 필요하다.

### 2.1 웨이브 구역 (`WaveZone`)

맵을 구간으로 나누고, 구간마다 웨이브 설정을 준다. 분대 중심이 들어가 있는 구역의 설정이 적용된다.

| 항목 | 뜻 | 초기값 예 |
| --- | --- | --- |
| 구역 모양 | 자식 점으로 그리는 닫힌 도형(외곽선과 같은 방식) | |
| Interval | 웨이브 간격(초) | 초반 12, 후반 5 |
| Count | 웨이브 하나의 적 수 | 초반 8, 후반 30 |
| Mobs | 나오는 적 종류와 비율 | |
| Spawn Points | 이 구역에서 쓰는 스폰 지점들(비우면 자동) | |

- **"끝 지점으로 갈수록 더 어렵고 자주"** 는 구역을 길을 따라 여러 개 놓고 뒤쪽 구역의 값을 높여 만든다.
- **"멈춰 있어도 주기가 짧아지지 않는다"** 는 저절로 지켜진다. 같은 구역 안에 있으면 설정이 그대로다.
- **3스테이지의 몰려오는 구간**은 간격이 아주 짧고 적 수가 많은 구역 하나다. 별도 시스템이 필요 없다.
- 구역이 겹치면 Hierarchy에서 아래에 있는 것이 우선한다(외곽선의 자식 순서와 같은 감각). 어느 구역에도 속하지 않은 곳에서는 웨이브가 나오지 않는다. 시작 지점 주변을 비워 두면 숨 고를 공간이 된다.
- 구역을 옮겨 가도 타이머는 이어진다. 구역을 넘는 순간 웨이브가 바로 터지지 않는다.
- Scene 뷰 표시: 구역 테두리와 "12초 / 8마리" 같은 요약 글자.

### 2.2 스폰 지점 (`SpawnPoint`)

적이 나타나는 위치다. 빈 오브젝트를 놓으면 된다.

- 웨이브가 나올 때, 그 구역의 스폰 지점 중 **분대에서 일정 거리 이상 떨어지고 화면에 보이지 않는** 지점을 골라 나눠서 내보낸다.
- 쓸 수 있는 지점이 없으면(전부 화면 안이거나 너무 가까우면) 분대 주변의 화면 밖 이동 가능 칸에서 자동으로 고른다. 스폰 지점을 하나도 놓지 않아도 게임은 돌아간다.
- 스폰 지점은 이동 가능한 칸 위에 둔다. 아니면 가장 가까운 이동 가능 지점으로 옮겨진다.
- 동시 최대 200마리는 유지한다. 상한에 닿으면 그 웨이브는 줄여서 내보낸다.

### 2.3 미니 보스 위치 (`MiniBossSpawn`)

미니 보스가 나타날 자리에 오브젝트를 놓는다.

| 항목 | 뜻 | 초기값 |
| --- | --- | --- |
| 위치 | 오브젝트의 위치 | |
| Definition | 어떤 미니 보스인지(체력·속도·공격 패턴 묶음 에셋) | |
| Trigger Radius | 분대 중심이 이 반경 안에 들어오면 등장 | 12 |

- 분대가 다가오기 전에는 미니 보스가 없다. 반경에 들어오는 순간 등장 연출과 함께 나타난다.
- Scene 뷰 표시: 미니 보스 자리에 표식, Trigger Radius 원.
- 한 스테이지에 여러 개를 놓을 수 있게 하되, 클리어 조건은 "모든 미니 보스 처치"로 둔다.
- 미니 보스는 끝 지점 앞에 두는 것을 권한다. 쓰러뜨린 뒤 끝 지점까지 가는 구간이 짧아진다.

### 2.4 클리어 조건

`StageSetup`에 선택 값 하나를 둔다.

| 값 | 뜻 | 쓰는 스테이지 |
| --- | --- | --- |
| 미니 보스 처치 후 끝 지점 도달 | 미니 보스가 살아 있으면 끝 지점에 가도 넘어가지 않는다 | 1, 2, 4 |
| 끝 지점 도달 | 닿기만 하면 된다 | 3 |
| 보스 처치 | 끝 지점 없음 | 5 |

끝 지점이 "아직 닫혀 있음"과 "열림"은 화면에서 구분되어야 한다(색이나 이펙트).

## 3. 미니 보스 연출

### 3.1 흐름

```
플레이 중
  → 분대가 Trigger Radius 진입
  → [등장 연출]  게임 진행 멈춤, 카메라가 미니 보스로 이동, 등장 이펙트·이름 표시
  → 플레이 재개 (미니 보스 전투)
  → 미니 보스 체력 0
  → [사망 연출]  게임 진행 멈춤, 카메라가 미니 보스로 이동, 사망 이펙트
  → 플레이 재개, 끝 지점 열림
```

### 3.2 연출 중의 규칙 (제안)

- **게임 진행을 멈춘다.** 분대, 적, 투사체, 장판 타이머, 웨이브 타이머, 부활 게이지가 모두 정지하고 입력을 받지 않는다. 연출을 보는 동안 맞아 죽는 일이 없어야 한다.
- 일시정지(P)와는 별개의 상태다. 연출 중에도 이펙트와 카메라는 움직여야 하므로 `Time.timeScale`을 0으로 두지 않고, 게임 진행 쪽 Tick만 건너뛴다.
- 연출이 끝나면 카메라는 연출 전 위치로 돌아간다.
- 길이는 짧게: 등장 2초, 사망 1.5초. 미니 보스 에셋의 값으로 둔다.
- 건너뛰기 키는 두지 않는다(2초라 필요 없다).

### 3.3 아티스트가 연출을 바꿀 수 있게

미니 보스 에셋(`Definition`)에 다음을 둔다.

| 항목 | 뜻 |
| --- | --- |
| Intro Duration / Death Duration | 연출 길이(초) |
| Intro Fx / Death Fx | 그 순간 미니 보스 위치에 생성할 이펙트 프리팹 |
| Display Name | 등장 때 화면에 띄울 이름 |

코드는 "카메라 이동 → 프리팹 생성 → 정해진 시간 대기 → 복귀"만 한다. 이펙트의 내용은 프리팹 안에서 아티스트가 만든다. 프리팹이 비어 있으면 카메라 이동과 이름 표시만 나온다.

### 3.4 사망 뒤 남은 적 (미정)

미니 보스가 죽은 뒤 끝 지점까지 가는 동안 어떻게 할지 정해야 한다.

| 선택지 | 내용 |
| --- | --- |
| (가) 웨이브 정지 + 남은 잡몹 전멸 | 사망 연출과 함께 화면의 적이 쓸려 나간다. 끝 지점까지는 승리 구간 |
| (나) 웨이브 정지, 남은 잡몹은 그대로 | 남은 적만 정리하거나 피해서 간다 |
| (다) 그대로 계속 | 웨이브가 계속 나온다 |

**제안: (가).** 미니 보스 처치의 보상이 분명하고, 연출과 잘 맞는다.

## 4. 부활 액션과 분대장 (결정 #38·#39)

### 4.1 부활 액션 확정 사항

결정 #27에 더해:

- **살리는 유닛은 그 3초 동안 사격하지 못한다.** 살리는 모션과 이펙트가 재생된다.
- **살아나는 위치는 진형의 중심 근처**다. 정중앙은 분대장 자리이므로 피한다. 살아난 유닛은 비어 있는 진형 자리로 자동으로 이동한다.

구현 메모:

- 살아나는 지점: 분대 중심에서 반경 1.0 안팎의 원 위. 여러 명이 동시에 살아나면 각도를 나눠 서로 겹치지 않게 한다. 그 지점이 이동 불가면 가장 가까운 이동 가능 지점.
- 살리는 유닛의 상태 "살리는 중"은 사격 불가 조건에 하나 추가하면 된다(`FireRules.CanFire`).
- 모션과 이펙트는 아트가 붙을 자리만 만든다: 살리는 유닛에 "살리는 중" 표시, 완료 순간 살아나는 지점에 이펙트 프리팹.

### 4.2 분대장

- 유닛 하나가 **분대장**이다. 분대장은 **항상 진형의 중심**에 선다.
- 진형 슬롯 생성은 이미 "살아 있는 인원수만큼 원점에서 바깥으로 채움"이므로, 원점 슬롯을 분대장에게 고정 배정하면 된다. 재배정에서 분대장은 제외한다.
- 원형 진형은 중심이 비어 있었다. 분대장이 생기면 원 한가운데에 분대장 혼자 서게 된다. 중앙 폭발 패턴(core)을 원형으로 피할 때 분대장만 맞는다. **의도인지 확인이 필요하다.**

**미정**

- 분대장이 죽으면 어떻게 되나: 게임 오버 / 다른 유닛이 분대장이 됨 / 분대장 없이 진행하고 부활로 되살림.
- 분대장도 살리는 유닛으로 뽑힐 수 있나.
- 분대장은 겉모습이 다른가(아트 필요 여부).

## 5. 아티스트·기획자가 하게 될 일 (구현 후 안내 문서로 옮김)

1. 맵에 `WaveZone`을 길을 따라 여러 개 그리고 뒤쪽일수록 값을 높인다.
2. `SpawnPoint`를 길 옆, 화면 밖이 될 만한 곳에 놓는다(생략 가능).
3. 미니 보스 자리에 `MiniBossSpawn`을 놓고 종류를 고른다.
4. `StageSetup`에서 클리어 조건을 고른다.
5. 미니 보스 에셋에 등장·사망 이펙트 프리팹을 넣는다.
