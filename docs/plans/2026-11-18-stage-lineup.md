# 스테이지 구성 기획 정리

> 상태: **기획자 원문 + 해석 + 구현에 필요한 것**. 원문은 기획자가 작성했고 ansirh가 2026-11-18에 전달했다. 해석과 "필요한 것"은 sub-1 세션이 붙였으며 확인 전이다.
> 기준 코드: main `643dbfb` 시점.

## 1. 기획자 원문

> **[1 스테이지]** : 평야에서는 e투석병
> v자 이동으로 1스테이지는끝남 e투석병 4기등장
> (초반 1자지형에서 2기 조우)
> 나중에 v자에서 1기조우 + ab기본개체 웨이브 늘어남
> 마지막에 Q강제하는 검정불꽃마법사 + ab기본개체 웨이브 늘어남
>
> **[2스테이지]** : 성초입 1자 대포가많은 구조 대포 3대가 불규칙적으로 패턴 전개하고
> 3기파괴되면 대포 1기와 창투척병 등장 +
> 2스테이지 아직 성벽안만났을때는
> 쫄몹만 만나다가 그림자검사 1개체 + ab
>
> **[3. 스테이지 초반은구상중]** ( e투석대포 개체 다량등장 예정) + 회전패턴 첫등장 **염동력사용 마법사 마지막 웨이브와 대포 투석속도 매우빨라짐으로 성내부에 몸을던져야 살아남는 연출
>
> **[4. 스테이지]** 는 w패턴 + 염동력개체 등장 1회
> r패턴 + 염등력개체 등장 1회

ansirh의 설명: 미니 보스는 5종이다 — **e투석병**(E 진형을 눌러서 피해야 하는 공격을 하는 미니 보스. 투석병과 대포는 같은 말), **검정불꽃마법사**, **창투척병**, **그림자검사**, **염동력사용 마법사**.

## 2. 용어 풀이

기획 원문의 Q·W·E·R은 진형 키다(결정 #19). 각 진형이 피하는 장판은 M1에서 정해져 있다.

| 키 | 진형 | 이 진형으로 피하는 장판 | 코드의 패턴 |
| --- | --- | --- | --- |
| Q | 밀집 | 바깥 고리 | Shell |
| W | 일자 | 양옆 띠 | Gate |
| E | 원형 | 중앙 폭발 | Core |
| R | 십자 | 네 모서리 | Quadrant |

- "e투석병" = 중앙 폭발(Core)을 쓰는 미니 보스. 원형(E)으로 피한다.
- "Q강제하는" = 바깥 고리(Shell)를 쓴다. 밀집(Q)으로 피한다.
- "w패턴", "r패턴" = 양옆 띠(Gate), 네 모서리(Quadrant).
- "ab기본개체" = 소형 몹 2종(근접, 원거리)으로 읽었다.
- "회전패턴" = 진형을 **회전**(마우스 휠, 결정 #16)시켜야 피할 수 있는 장판으로 읽었다. **확인 필요.**

## 3. 스테이지별 정리

| 스테이지 | 장소·지형 | 미니 보스 | 웨이브 | 클리어 |
| --- | --- | --- | --- | --- |
| 1 | 평야. 일자 구간 → V자로 꺾임 | 투석병: 일자 구간에서 2기, V자에서 1기. 마지막에 검정불꽃마법사 1기 | V자부터 늘어나고 마지막에 더 늘어남 | 미니 보스 처치 후 끝 지점 |
| 2 | 성 초입. 일자, 대포가 많음 | 성벽 전: 그림자검사 1기. 성벽: 대포 3기가 불규칙하게 패턴 전개 → 3기 파괴 시 대포 1기 + 창투척병 등장 | 성벽 전에는 잡몹만 | 미니 보스 처치 후 끝 지점 |
| 3 | (초반 구상 중) 끝이 성 내부 | 투석 대포 다수. 회전 패턴 첫 등장. 마지막에 염동력 마법사 | 마지막 웨이브에서 대포 투석 속도가 매우 빨라짐 | 성 내부(끝 지점)로 뛰어들면 클리어 |
| 4 | (미기재) | 염동력 마법사 2회: 한 번은 W 패턴과, 한 번은 R 패턴과 | (미기재) | 미니 보스 처치 후 끝 지점 |
| 5 | (미기재) | 보스 | | 보스 처치 |

## 4. 미니 보스 5종

| 미니 보스 | 패턴(원문에서 읽은 것) | 정해지지 않은 것 |
| --- | --- | --- |
| 투석병(대포) | 중앙 폭발 → 원형(E) | 움직이는지. 2스테이지의 "대포"는 성벽에 고정된 것으로 읽힌다 |
| 검정불꽃마법사 | 바깥 고리 → 밀집(Q) | |
| 창투척병 | 원문에 없음 | 어떤 장판을 쓰는지 |
| 그림자검사 | 원문에 없음 | 어떤 장판을 쓰는지 |
| 염동력 마법사 | 회전 패턴. 4스테이지에서는 양옆 띠(W), 네 모서리(R)와 함께 | "회전 패턴"의 정확한 뜻 |

공통으로 정해지지 않은 것: 종류별 체력, 이동 속도, 공격 간격.

## 5. 지금 구현으로 되는 것과 안 되는 것

| 기획 요소 | 지금 구현 | 필요한 것 |
| --- | --- | --- |
| 미니 보스 여러 종류 | 정의 에셋 구조는 있음(`EliteDefinition`). 에셋은 1개(Brute) | 종류별 에셋 5개. 패턴 묶음만 다르게 주면 됨(데이터 작업) |
| 한 스테이지에 미니 보스 여러 마리 | 가능(`MiniBossSpawn` 여러 개, 전부 처치해야 끝 지점 열림) | |
| 지점마다 등장 | 가능(Trigger Radius) | |
| 중앙 폭발, 바깥 고리, 양옆 띠, 네 모서리 | 있음 | |
| **고정된 대포** | 미니 보스는 분대를 향해 걸어온다 | 움직이지 않는 설정(속도 0)과 그때의 동작 확인 |
| **대포 3기가 동시에 불규칙하게 패턴 전개** | 여러 마리 동시 시전은 가능. 간격은 일정(`Attack Gap`) | 간격에 무작위 범위. 장판 3개가 동시에 예고될 때 화면에서 읽히는지 확인 |
| **"3기 파괴되면 대포 1기와 창투척병 등장"** | 등장 조건은 분대의 접근뿐 | 다른 미니 보스가 죽으면 등장하는 조건 |
| **회전 패턴** | 장판에 각도가 없다. 장판은 항상 월드 축에 맞춰져 있음 | 장판에 회전 각도 추가(판정과 표시 모두). 뜻이 확인돼야 설계 가능 |
| **대포 투석 속도가 매우 빨라짐** | 공격 간격이 고정 | 진행도나 시점에 따라 공격 간격이 줄어드는 설정 |
| **V자 지형, 성벽, 성 내부** | 이동 가능 범위 기능으로 맵 제작 가능 | 아티스트 맵 작업 |
| **특정 지점에서 웨이브가 늘어남** | 진행도 곡선으로 표현 가능 | 곡선 값 |
| **원거리 소형 몹** | 근접만 있음 | 적 투사체(새 게임플레이) |
| 등장·사망 연출 | 미니 보스마다 등장 2초, 사망 1.5초 동안 게임이 멈춤 | 한 스테이지에 4~5마리라 매번 멈추면 흐름이 끊긴다. 연출을 건너뛰는 설정이 필요할 수 있음 |
| 사망 시 잡몹 전멸(결정 #42) | 미니 보스가 죽으면 잡몹 전멸 + 웨이브 정지 | 여러 마리인 스테이지에서 매번 적용할지, 마지막 한 마리에만 적용할지 |

## 7. 확인이 필요한 것

1. **회전 패턴이 무엇인가.** 장판이 비스듬히 놓여 진형을 돌려야 피하는 것인지, 장판 자체가 돌아가는 것인지.
2. **창투척병과 그림자검사의 장판.**
3. **대포(투석병)는 고정인가, 걸어오는가.**
4. **3스테이지에 미니 보스가 있는 것으로 바뀌었는가.** 그렇다면 잡지 않고 끝 지점에 닿기만 하면 클리어인가.
5. **미니 보스가 여러 마리일 때** 등장·사망 연출과 잡몹 전멸을 매번 할지, 마지막에만 할지.
6. 1스테이지 투석병이 3기인지 4기인지.
7. 4스테이지의 지형과 웨이브, 5스테이지 보스전에 잡몹이 나오는지.
